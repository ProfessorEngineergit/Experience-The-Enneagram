# Experience The Enneagram

Interaktive deutschsprachige Website mit Beschreibungen der neun Enneagramm-Typen und einem Fragebogen. Die Umsetzung besteht aus HTML, CSS und JavaScript.

## Ansehen

```sh
python3 -m http.server 8080
```

Im Browser `http://localhost:8080` öffnen. Einstiegspunkt ist `index.html`; die Interaktion liegt in `script.js`.

## Einordnung

Experimentelle Informations- und Reflexionsseite. Der Fragebogen ist kein diagnostisches Verfahren; eine wissenschaftliche Validierung dieser konkreten Auswertung ist im Repository nicht dokumentiert.
